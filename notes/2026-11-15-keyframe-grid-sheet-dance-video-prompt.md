## 1. 核心技巧與兩階段 Prompt 模板

### 1.1 核心機制：Keyframe Grid + 雙圖參照 + BPM 數學鎖定
直接給影片模型單張圖並要求「跳 8 秒舞」，極易在 3 秒後動作重複、肢體崩壞或服裝漂移。本技巧將「動作設計」與「動態補間」拆成兩步：
1. **Step 1（靜態關鍵幀展開）**：用高精度生圖模型把完整 8 秒動作拆成一張 `4×4`（16 格，白底細格線、左上角標 `1–16`、全身不裁切）動作關鍵幀表，要求包含「開場 → 推進 → 高潮 → 收尾」完整起承轉合。
2. **Step 2（雙圖參照＋時間節奏鎖死）**：將 **圖 1（16 格舞步表）** 與 **圖 2（原角色設定圖，鎖定臉部／髮型／服裝細節）** 一同送入支援多圖參照的影片模型，利用 `8 秒 / 16 格 = 0.5 秒/格 = 120 BPM（一拍 0.5 秒）` 鎖定節奏與單一固定平視鏡頭，並明令禁止格線與文字殘留。

### 1.2 可複用中文 Prompt 模板（可替換：角色、秒數、格數、BPM）

```text
[Step 1｜生成 4×4 關鍵幀動作表]
用上傳的角色圖做一張 4×4 舞步表，一張方圖、16 格大小一樣。
角色的臉、髮型、配色、身材比例、服裝配件、畫風全部照參考圖，不要重新設計。
依角色個性自動選舞風（活潑、優雅、帥氣、可愛、沉穩皆可）。
16 個動作要是同一段舞，照左到右、上到下排，有開場、推進、高潮、收尾。
白底、細格線，每格左上角標 1 到 16，每格只有一個全身角色，鏡頭固定。
避免：重複動作、臉跑掉、換衣服、比例不一、多手多腳、身體被裁切、背景道具、文字。

[Step 2｜雙圖生成 8 秒連貫影片]
8 秒方形 2D 動畫舞蹈，全身單一鏡頭。
圖 1：照 16 個動作的順序，每 0.5 秒一個，動作之間順順接過去。
圖 2：鎖住角色外型與服裝（逐項列出髮型、配件、衣服特徵）。
固定平視鏡頭，白色地板加淡淡的影子，節奏 120 BPM 純音樂。
不要剪接、不要多出人、不要格線文字。
```

## 2. 技術評估與適用邊界

- **高度可遷移的通用手法**：此「`N×M` 關鍵幀網格圖＋原畫鎖定圖」不僅能用於跳舞，亦適用於角色打招呼、武打連招、動作教學或吉祥物轉場動畫。
- **實務失敗點與注意事項**：
  1. **雙圖參照能力前提**：Step 2 依賴影片模型對「圖 1（動作序列）與圖 2（角色外觀）」的多圖區分理解；若模型不支援強多圖參照，容易把格線或數字 `1–16` 閃現進成片，或誤讀成 16 宮格分割畫面。
  2. **16 格全身不裁切**：Step 1 若有單格手腳被裁切或人物縮放比例不一致，影片補間會產生明顯尺寸跳動。
  3. **版權邊界**：商業或公開專案應使用原創角色設定圖，避免直接使用現成動漫 IP 角色。
