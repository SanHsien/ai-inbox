## 1. 核心內容摘要與技術深挖

### 1.1 什麼是「靶心人故事編輯器」Prompt？
本 Prompt 將當代華文小說家兼編劇大師**許榮哲**經典的「**靶心人故事公式**」（目標 $\to$ 阻礙 $\to$ 努力 $\to$ 結果 $\to$ 意外 $\to$ 轉彎 $\to$ 結局），跳脫出傳統靜態文字與 Markdown 表格的輸出限制，以**生成式 UI（Generative UI）**與**前端互動軟體工程**規格，要求 AI 模型直接輸出一個在對話介面中具備**單頁狀態管理（In-dialog State Management）**、**可點擊互動、多層鑽取（Drill-down）與即時雙向資料綁定**的故事編輯器。

### 1.2 核心規格細部拆解

#### A. 第一層：靶心人故事總圖（七節點與三因果箭頭）
1. **排版拓撲**：
   - 採 **三欄四排 V 字型對稱排列**。
   - 第四排左右留白，僅中央放置「D 結果」，使故事推進呈現自目標下沉至結果、再因意外與轉彎攀升至結局的視覺 V 字起伏。
2. **七節點定義與嚴格字數契約**：
   - **A 目標**：主角最初希望完成什麼？
   - **B 阻礙**：什麼困難阻止主角達成目標？
   - **C 努力**：主角做了哪些具體行動？
   - **D 結果**：行動最後帶來什麼實際結果？
   - **E 意外**：努力之後發生什麼未預期的事情？
   - **F 轉彎**：主角因阻礙改變了什麼方法或方向？
   - **G 結局**：最後獲得什麼超越原目標的收穫？
   - **文字契約**：每個節點固定顯示 **4 句，每句恰好 7 個中文字（共 28 字）**。文字必須連貫且忠於原文；若原文無此階段證據，直接標註「**缺失**」，嚴禁為湊字數捏造情節。
3. **三因果向右箭頭（H1～H3）與因果真偽校驗**：
   - 位於總圖中央欄，採用向量 SVG 向右箭頭渲染，內嵌 **2 句 7 字因果說明（共 14 字）** 及因果強度標籤（強 / 普通 / 弱 / 缺失）。
   - **H1（A $\to$ G，結局高於目標）**：檢驗結局是否在精神、境界或收穫上實質超越最初目標。
   - **H2（B $\to$ F，轉彎藏在阻礙）**：檢驗轉彎是否由特定阻礙直接觸發，拒絕突兀的天降神兵。
   - **H3（C $\to$ E，意外來自努力）**：檢驗意外是否為先前努力的連鎖副產物。
   - **核心哲學防線**：嚴格區分「時間先後」與「因果必然」（Post hoc ergo propter hoc 檢驗），杜絕把「先發生 A 再發生 B」誤判為「A 導致 B」。

#### B. 第二層：節點 3×3 九宮格鑽取編輯器
- **零延遲切換**：點擊任一 A～G 節點，在同一個互動 Widget 內原地翻轉至該節點的 3×3 九宮格，**不得重新觸發 LLM 對話或重新載入頁面**。
- **九宮佈局**：
  - 中央格：節點核心 28 字摘要。
  - 周圍八格：原文證據、具體事件、人物、行動、細節、懸念問題、補充說明、AI 推論。
- **雙向資料同步（Two-way Data Binding）**：在九宮格中修改文字，點擊「返回故事總圖」後，外層摘要立即即時更新。

#### C. 三伏三冒長距離伏筆校驗分頁
- 從文本中萃取 3 組長距離跨度關係（伏一 $\to$ 冒一、伏二 $\to$ 冒二、伏三 $\to$ 冒三）。
- 每組記錄伏筆原文位置、回收原文位置、服務節點、以及**鬆緊評估（太鬆 / 剛好 / 太緊 / 缺失）**，檢驗故事鋪陳的收斂張力。

#### D. 防幻覺與軟體交付鐵律
1. **純前端互動狀態**：必須具備真實狀態管理（React Hooks / Vanilla JS State Machine），禁止把按鈕做成無功能的裝飾品。
2. **原文證據與 AI 推論分離**：嚴格標註何者為原文摘錄、何者為模型推論。
3. **單一結構弱點指出**：編輯器底部增加「最需要修正的一處」，直接點出全文最薄弱的因果斷裂點。
4. **一鍵匯出**：提供「複製完整故事結構」功能，便於將結構化 JSON / Markdown 攜帶至其他工具鏈。

## 2. 對現有系統的啟發與適用性評估

- **對應現有系統 / 專案**：
  - **Antigravity 內建 `generative_ui` Skill**：
    Antigravity 原生支援內嵌 HTML/React 的 Generative UI 互動卡片。本 Prompt 的規格為 Antigravity 產出高階互動型審查工具（如 PRD 審查器、架構因果圖、代碼變更影響編輯器）提供了標準典範。
  - **劇本創作與短劇工作流（`ai-short-drama-screenwriter`）**：
    在短劇、廣告腳本與產品故事的開發中，將此編輯器作為結構化驗收門檻，能精準過濾掉「節奏拖沓、意外未由努力引起、結局低於目標」的平庸劇本。
  - **因果審查與防幻覺哲學（`buddhist-method` / `verification-protocol`）**：
    Prompt 中「時間先後不等於因果」與「無證據即填缺失」的原則，正是工程防幻覺與如實客觀的具體體現。

- **落差與採納判斷**：
  - **極具實用價值的採納點**：
    1. 將此 Prompt 封裝為標準可執行的 Antigravity Generative UI 元件樣板（HTML/Tailwind/Alpine.js 或 React）。
    2. 提煉其「字數契約 + 因果強度 + 三伏三冒鬆緊評估」為自動化文本檢驗邏輯。
