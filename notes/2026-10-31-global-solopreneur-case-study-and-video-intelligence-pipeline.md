## 3. 影音情報自動化萃取管線（Video Intelligence Pipeline）

將長篇 YouTube 專訪與一手案例轉化為可落地執行的工程規格，依賴結構化的情報萃取架構：

```mermaid
flowchart TD
    A["YouTube 專訪 / 一手案例影片 (URL)"] --> B["音訊/字幕軌抓取 (Transcript API / yt-dlp)"]
    B --> C["沉浸式翻譯雙語對照 / 語音轉文字 Whisper"]
    C --> D["時間戳標記與高光段落過濾 (Glasp / Litit 規則)"]
    D --> E["LLM 結構化轉錄中樞 (Claude / Antigravity)"]
    E --> F["5W1H 商業畫布輸出"]
    E --> G["48 小時行動檢核清單 (Noah Kagan 式驗證)"]
    E --> H["一人公司可複用 Prompt / Skill 模組"]

    classDef process fill:#f0f8ff,stroke:#4682b4,stroke-width:2px;
    classDef output fill:#f5fff0,stroke:#2e8b57,stroke-width:2px;
    class B,C,D,E process;
    class F,G,H output;
```

### 情報萃取標準輸出欄位（Case Study Schema）：
1. **問題定義（Problem）**：創業者解決了誰的什麼具體痛點？痛點是否具備支付意願？
2. **驗證方式（Validation）**：最初如何在不寫複雜程式碼的情況下獲取第 1 個付費客戶？
3. **獲客漏斗（Acquisition Funnel）**：前 100 個使用者的具體來源（冷郵件、SEO、Product Hunt、社群私訊）。
4. **財務與單位經濟（Unit Economics）**：定價策略（訂閱制 vs 單次買斷）、毛利率、維運成本。
5. **關鍵轉折點（Pivots & Breakthroughs）**：什麼動作觸發了指數型成長？
