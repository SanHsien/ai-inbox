## 0. 原始資料盤點（X 貼文、串文與 `search_web` 查證）

- **第二輪資助方案內容**：
  - 名額由第一輪的 `5,000` 個翻倍至 **`10,000` 個**。
  - 提供 **6 個月、每月 \$100 美元額度的 ChatGPT Pro 方案**（含 Codex；依 OpenAI 官方計畫說明亦視專案含 Codex Open Source Fund API 點數與 Codex Security 試用）。
  - **曾獲第一輪資助者明確鼓勵重新申請**。
- **過去半年開源投入回顧（作者續寫串文 `2099965141563437334`）**：
  - 第一輪 `5,000` 份 Codex-for-OSS 資助；
  - 透過 GitHub Sponsors 直接贊助 `\$160,000` 美元；
  - 以白金贊助商身分贊助 Rust Foundation `\$600,000` 美元。
- **申請門檻差異（`search_web` 補充）**：
  - 相較競品（如 Anthropic 針對開源維護者的 Claude Max 計畫設 5,000+ GitHub Stars 或 100 萬+/月 npm 下載量等硬性門檻），OpenAI 的 Codex for Open Source **不設單一硬性星數下限**，而是依專案在生態系中的重要性與活躍維護狀態評估，讓中小型或單人維護專案也有機會申請。
