## 1. 核心宣稱真假查證（CQR 檢驗）

- **Claim（宣稱）**：靠 Amazon Associates 聯盟分潤可穩定「每天進帳 50–100 美元（約新台幣 1,600–3,200 元／月入 4.8 萬–9.6 萬元）」，當成零用錢並不困難。
- **Evidence（官方規則與單位經濟試算）**：
  1. **真實抽成比例（US Amazon Associates Fee Schedule）**：
     - 高毛利少數品類（Luxury Beauty）：`10%`
     - 書籍／廚具／汽配：`4.5%`；服飾／Amazon 裝置／玩具／戶外運動：`4%`；居家／家具／工具／寵物／美妝：`3%`；PC 零組件：`2.5%`；電視／數位遊戲：`2%`；生鮮／日用品：`1%`；禮品卡／訂閱等：`0%`。
     - 多數日常品類實務加權平均約 **`2.5% – 4%`（以 `3%` 估算）**。
  2. **Cookie 視窗與入門淘汰線**：
     - **24 小時 Cookie 視窗**（點擊後 24 小時內購買才算；若在 24 小時內加入購物車，該商品可延長保留 89 天）。
     - **180 天 3 筆合格銷售**：新帳號須在 180 天內完成至少 3 筆合格成交才會進入人工網站／流量審核，未達標直接關帳。
  3. **日賺 50–100 美元所需流量反推（以 3% 抽成、平均客單價 $40 美元計算）**：
     - 月佣金目標：`$1,500 – $3,000 美元` $\Rightarrow$ 需帶動月成交額（GMV）：**`$50,000 – $100,000 美元`**（日均成交 `$1,667 – $3,333`）。
     - 日均成交筆數：約 **42 – 83 筆實際下單／天**。
     - 以 2%–5% 電商點擊轉換率反推：每天需要 **1,000 – 4,000 次高購買意圖點擊**（對應月瀏覽量通常達數萬至十數萬的英文 SEO 評測站、YouTube 頻道或大型社群）。
     - 台灣創作者另有跨國收款門檻（電匯／Payoneer 匯損）與美國 W-8BEN 稅務申報成本。
- **Reasoning（真假結論）**：
  - **機制真實、敘事誤導（嚴重的倖存者偏差）**：對於**已經建成穩定英文搜尋流量或大型開箱頻道**的成熟站長而言，日入 $50–$100 美元完全可能；但將月收近新台幣 5–10 萬元的營運結果輕描淡寫成「補個零用錢沒問題」，刻意省略了英文流量取得成本、24 小時極短 Cookie 限制、180 天審核門檻與前期 0 收入累積期，對一般新手極具誤導性（常見於販售「AI 自動做亞馬遜分潤站」課程或群組的引流話術）。

### 2.1 補充查證：蝦皮影音「選品 → AI 重產圖轉片 → Android 無 API 自動上架」流程評估（2026-11-15）

針對社群討論的 Python + Android 自動化蝦皮影音分潤流水線（`選品 → AI 重新產圖 → 人工驗證 → 轉影片 → Android 手機無官方 API 自動上架`），結合蝦皮官方創作者規範與分潤實務查證結果如下：

1. **為何討論串強調「不能直接用商家圖、須 AI 重新生成」**：
   - 未經授權直接搬運賣家商品圖、品牌商標或既有影片剪輯，容易觸犯蝦皮影音的原創性與智慧財產權規範，進而遭下架或扣分。
   - **合規盲區（AI 標記強制規定）**：依蝦皮影音創作者規範，凡使用 AI 生成畫面、語音、虛擬人像或腳本的影片，**發布前必須開啟「AI 生成影片標記」**（發布後無法補開），未依規定標示將面臨違規處分。
2. **為何「發了一堆完全沒訂單」（平台限流與分級機制）**：
   - **創作者分級制度（Creator Levelling Program）**：蝦皮影音每週依過去 28 天表現評估 `Lv.0–Lv.2` 等級；低品質、同質化、無實質使用體驗或純圖片拼貼幻燈片（Slideshow）的批次 AI 短片，會被演算法判定為低質／重複內容而遭限流，曝光停留在極低水位。
   - **模型話術誤差**：討論串提及「預設 `Gemini 3.8 Flash`」與實測現行模型版本不符（屬口誤或誤植），且即便改用 Grok / OpenAI 產圖轉片，**決策瓶頸不在模型畫質，而在缺乏真實開箱／使用場景的同質化短片無法產生轉換率**。
3. **Android 無 API 自動上架的技術可行性與封號風險**：
   - 技術上可透過 ADB、UIAutomator 或 Auto.js 模擬點擊蝦皮 App 達成無官方 API 自動上傳與掛橘色購物袋（單支最多 6 件商品，基礎分潤約 0.5%–3%＋賣家加碼）。
   - 但批量自動發片搭配同質化 AI 內容，極易觸發平台反垃圾與異常行為偵測（嚴重可連帶凍結分潤與買賣家帳號），屬於「技術可行但商業 ROI 為負、帳號風險極高」的做法，維持第 3 節「不建立自動化洗片工程任務」的決策。

## 3. 評估結論與待辦事項決策

- **是否納入開發／工作流待辦**：**暫不建立工程任務**。
