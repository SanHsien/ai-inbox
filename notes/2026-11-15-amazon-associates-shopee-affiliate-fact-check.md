## 1. 核心宣稱真假查證（CQR 檢驗）

- **Claim（宣稱）**：靠 Amazon Associates 聯盟分潤可穩定「每天進帳 50–100 美元（約新台幣 1,600–3,200 元／月入 4.8 萬–9.6 萬元）」，當成零用錢並不困難。
- **Evidence（官方規則與單位經濟試算）**：
  1. **抽成比例（[US Amazon Associates 官方費率表](https://affiliate-program.amazon.com/help/node/topic/GRXPHT8U84RAYDXZ?force_isolation=true)）**：
     - 高毛利少數品類（Luxury Beauty）：`10%`
     - 書籍／廚具／汽配：`4.5%`；服飾／Amazon 裝置：`4%`；玩具／戶外運動／居家／家具／工具／寵物／美妝：`3%`（原稿把玩具、戶外運動寫成 4%，官方表為 3%）；PC 零組件：`2.5%`；電視／數位遊戲：`2%`；生鮮／日用品：`1%`；禮品卡等：`0%`。部分訂閱計畫另有獨立的註冊獎勵（bounty），不能一律算 0%。
     - 下面試算用 **`3%`** 當假設值；這不是實測的加權平均，沒有樣本數據。
  2. **Cookie 視窗與入門淘汰線**：
     - **24 小時視窗**（點擊後 24 小時內購買才算；[官方 FAQ](https://affiliate-program.amazon.com/help/node/topic/G9SMD8TQHFJ7728F) 說 24 小時內加入購物車的商品，通常在 90 天購物車到期前結帳仍可計。視窗也會因為下單或點了其他聯盟連結而提前關閉，不是固定 89 天的 cookie）。
     - **[180 天 3 筆合格銷售](https://affiliate-program.amazon.com/help/node/topic/G8TW5AE9XL2VX9VM)**：新帳號須在 180 天內完成至少 3 筆合格成交才會進入審核，未達標會被關閉；本人訂單不算。
  3. **日賺 50–100 美元所需流量反推（情境推算；3% 抽成、平均客單價 $40 美元、轉換率 2%–5% 都是假設）**：
     - 月佣金目標：`$1,500 – $3,000 美元` $\Rightarrow$ 需帶動月成交額（GMV）：**`$50,000 – $100,000 美元`**（日均成交 `$1,667 – $3,333`）。
     - 日均成交筆數：每筆佣金 40 × 3% = 1.2 美元，需約 **41.7 – 83.3 筆實際下單／天**。
     - 以 2%–5% 點擊轉換率反推：每天需要約 **833 – 4,167 次高購買意圖點擊**（對應月瀏覽量通常達數萬至十數萬的英文 SEO 評測站、YouTube 頻道或大型社群）。
     - 台灣創作者另有跨國收款門檻（電匯／Payoneer 匯損）與美國 W-8BEN 稅務申報成本。
- **Reasoning（真假結論）**：
  - **機制真實、敘事誤導（嚴重的倖存者偏差）**：對於**已經建成穩定英文搜尋流量或大型開箱頻道**的成熟站長而言，日入 $50–$100 美元完全可能；但將月收近新台幣 5–10 萬元的營運結果輕描淡寫成「補個零用錢沒問題」，沒有提到英文流量取得成本、24 小時視窗、180 天審核門檻與前期 0 收入累積期，新手容易低估難度。這是風險評估，不是查證結論：沒有這位網友的收入、成本資料，也沒有證據說他是故意省略或在替課程引流。

### 2.1 補充查證：蝦皮影音「選品 → AI 重產圖轉片 → Android 無 API 自動上架」流程評估（2026-11-15）

針對社群討論的 Python + Android 自動化蝦皮影音分潤流水線（`選品 → AI 重新產圖 → 人工驗證 → 轉影片 → Android 手機無官方 API 自動上架`），結合蝦皮官方創作者規範與分潤實務查證結果如下：

1. **為何討論串強調「不能直接用商家圖、須 AI 重新生成」**：
   - 未經授權直接搬運賣家商品圖、品牌商標或既有影片剪輯，容易觸犯蝦皮影音的原創性與智慧財產權規範，進而遭下架或扣分。
   - **合規盲區（AI 標記強制規定）**：依蝦皮影音創作者規範，凡使用 AI 生成畫面、語音、虛擬人像或腳本的影片，**發布前必須開啟「AI 生成影片標記」**（發布後無法補開；[蝦皮官方說明](https://help.shopee.tw/portal/4/article/201316)）。同一份說明也寫明 AI 標籤本身不影響曝光。
2. **為何「發了一堆完全沒訂單」（可能原因，無法查明個別創作者的實際原因）**：
   - **創作者分級制度（Creator Levelling Program）**：「每週依過去 28 天表現評估 `Lv.0–Lv.2`」這個分級細節未查證。官方只說違規或低品質內容可能降低曝光；低品質、同質化的批次 AI 短片有被降曝光的風險，但不能說是 AI 本身導致限流。
   - **模型話術誤差**：討論串提及「預設 `Gemini 3.8 Flash`」與實測現行模型版本不符（屬口誤或誤植），且即便改用 Grok / OpenAI 產圖轉片，**決策瓶頸不在模型畫質，而在缺乏真實開箱／使用場景的同質化短片無法產生轉換率**。
3. **Android 無 API 自動上架的技術可行性與封號風險**：
   - 技術上可透過 ADB、UIAutomator 或 Auto.js 模擬點擊蝦皮 App 達成無官方 API 自動上傳與掛橘色購物袋（「單支最多 6 件商品、基礎分潤約 0.5%–3%」未查證，也不足以代表現行費率；ADB／Auto.js 上架本身未實測）。
   - 但批量自動發片搭配同質化 AI 內容，極易觸發平台反垃圾與異常行為偵測（嚴重可連帶凍結分潤與買賣家帳號），評估為帳號風險高、報酬不確定的做法（沒有成本與收入數據，ROI 未計算），維持第 3 節「不建立自動化洗片工程任務」的決策。

## 3. 評估結論與待辦事項決策

- **是否納入開發／工作流待辦**：**暫不建立工程任務**。
  - **理由**：
    1. 聯盟分潤本質是**流量變現（Traffic Monetization）**，而非技術工具缺口；若無穩定的高意圖內容流量池，自動化產出分潤連結或 AI 洗文只會觸犯平台反垃圾條款導致封號。
    2. 本篇已完成「話術真假查證、單位經濟驗算、以及 Amazon／蝦皮／酷澎／台灣聯盟網規則對比」，留存知識庫作為未來評估商業模式或防範課程割韭菜之基準即可，不分散 `agent-relay`、`agent-advisor` 等核心專案精力。
