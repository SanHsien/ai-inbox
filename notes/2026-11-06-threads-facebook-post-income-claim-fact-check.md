## 1. 貼文原文

> 越來越多人知道臉書發文可以賺錢錢了，希望大家都可以繼續使用臉書擺脫經濟困難，畢竟臉書給的錢真的比很多一個月普通工作的收入還多

作者自留言補充：「補上我自己的後台資訊，右下角那個美金金額就是這張照片可以賺到的錢」，附 Facebook 專業後台「貼文詳細資料」截圖。

## 2. 作者自己的截圖就反證了主張

截圖數據（貼文「認識我－關於我的全部（2026 新版）」，發布於 **2025-09-13**）：

| 指標 | 數值 |
| --- | --- |
| 瀏覽次數 | 272 萬 |
| 互動次數 | 409,865 |
| 收益約略值 | **US\$130.33** |
| 新增追蹤 | 0 |
| 相對表現 | 比平均貼文多 **7,816%** 檢視 |

換算：

```text
每千次瀏覽收益 (RPM) = 130.33 / 2,720 ≈ US$0.048 ≈ NT$1.5
單篇爆文總收益       ≈ US$130 ≈ NT$4,200（累積約 14 個月）
一般貼文（÷ 79.16）  ≈ 3.4 萬次瀏覽 → ≈ US$1.6 ≈ NT$53
```

- 這是一篇 **約 79 倍於平均** 的離群爆文，且收益是長期累積，不是月收入。
- 想達到台灣普通月薪（約 NT\$3 萬）需每月約 **2 千萬次瀏覽**，等於每月生出 7 篇同級爆文。
- 「比月薪還多」的主張只可能是倖存者偏差，或刻意隱去分母。

## 3. 引流話術與農場訊號

1. **一字不差的複製貼文**：「Related threads」中 `@azzkk88` 同日發布 **完全相同** 的文案，屬於帳號矩陣／文案農場的典型特徵。
2. **留言模板化**：「我很需要」「想學習」「怎麼賺錢啊」等低資訊留言，用於拉高互動並導向私訊。
3. **同頁關聯貼文全是副業引流**：「如果有一個網路事業兼職…」「做什麼副業好呢」「一個人在家用網路賺錢」，標籤 `#兼職首選 #斜槓人生 #流量密碼`。
4. 少數清醒留言：「也沒那麼多其實」「門檻很高啊，追蹤人數至少一萬」「臉書不好賺吧」。

## 4. 平台事實（查證）

- Facebook 現行為整合式 **Content Monetization**（合併 In-Stream Ads、Ads on Reels、Performance Bonus），採邀請／專業後台申請制；台灣在支援地區內。
- 需 Page 或開啟 **Professional Mode** 的個人檔案、年滿 18 歲、遵守 Partner／Content Monetization Policies；**非原創、重複轉貼內容會被限制收益**，與上述複製貼上行為直接衝突。
- 收益與帳號、受眾地區、內容類型高度相關；作者截圖的 RPM ≈ US\$0.05 符合華語受眾低廣告單價的常態。
