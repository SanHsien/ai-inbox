# 主體資產盤點 (Subject Inventory) 與論證寫作前置提示詞範本

> 本範本源自開源專案 [`Leonxlnx/taste-skill`](https://github.com/Leonxlnx/taste-skill) (TasteSkill v2) 之核心設計哲學。  
> **核心痛點**：AI 生成的網頁往往陷入「平均化網頁陷阱（Average Landing Page Slop）」——置中標題、標籤小徽章、三個帶圖示的特性卡片、空泛的藍紫漸層與罐頭文案。這類頁面毫無設計決策，千篇一律。  
> **解法**：在撰寫任何 HTML / CSS / Tailwind / React 程式碼之前，強制執行「**主體資產盤點**」與「**爭點論證寫作 (Claim + Proof)**」，以實質獨特內容驅動排版佈局。  
> 交付形式：以 `ai-inbox` 範本（`templates/subject-inventory-argument-writing-prompt.md`）交付。

---

## 1. 前置提示詞模組（Prompt Template）

將以下系統指令注入前端開發 Agent 或對話開頭：

```markdown
### 前端設計硬門檻：主體資產盤點與區塊爭點論證協定

在為任何產品、品牌、活動或專案撰寫首頁（Landing Page）或展示頁代碼前，嚴禁直接套用「Hero -> 3 張 Feature Cards -> 評價輪播 -> 定價表」罐頭模板。你必須嚴格依序執行以下兩階段前置規劃，並輸出給使用者確認後，方可動手撰寫前端代碼：

#### 階段一：主體資產盤點 (Subject Inventory)
從使用者提供的 Brief 或背景中，主動深挖並條列 8~12 項「僅屬於該主體、無法套用到任何競品」的具體事實特徵：
1. **地理與物理座標**：具體產地、經緯度、海拔高度、微型氣候、土壤或建築特徵。
2. **時間尺度與節奏**：烘焙時間、採收季節、製程耗時、歷史年份、批次排程。
3. **精確數字與限制**：年產量上限、單批重量、特定溫度、容量、良率百分比。
4. **感官與實體材質**：麻布袋編號、黃銅質感、特定木質、牛皮紙觸感、顏色 HEX 碼。
5. **負向邊界與不妥協**：明文拒絕做的事（如「絕不混豆」、「絕不使用預磨粉」、「不接受代工」）。
6. **核心人物與角色**：具名技術者、傳承人、莊園主或首席開發者。

#### 階段二：爭點論證寫作 (Argument Writing: Claim + Proof)
頁面每一個區塊（Section）的存在，本質上都是對訪客的一場「論證」。嚴禁設立沒有實質證據的假大空區塊：
- 每個 Section 必須包含：
  - **爭點主張 (Claim)**：一句清晰、有態度、不可辯駁的論斷（非空洞形容詞）。
  - **硬核客觀證據 (Proof)**：數據、照片出處、官方檢驗報告、物理批次號、客戶原聲紀錄。
  - **排版與視覺承載 (Layout & Visual Direction)**：採用超大字級、大塊純色、雙欄強對比、歷史檔案圖庫（Public Domain）等，嚴禁罐頭圖示卡片。
- 若某個概念缺乏有力的 Proof，**直接刪除該區塊**，寧缺毋濫。
```

## 2. 隨機主題測試驗收示範：本地小農精品水洗咖啡

以下為依據本範本實際運行的標準前置論證輸出示範：

### 主題：阿里山特富野社「野雲」高海拔小農水洗藝伎咖啡

#### 階段一：主體資產盤點表 (Subject Inventory)

1. **地理座標**：嘉義縣阿里山鄉特富野部落（Tefuye），北緯 23°29'N，東經 120°45'E，海拔 1,280 公尺。
2. **土壤與氣候**：富含腐植質之黑砂壤土，午後穩定湧升濃霧，日夜溫差達 14°C，果實成熟期較平地拉長 45 天。
3. **品種與樹齡**：紅果藝伎（Geisha T.0287），樹齡 9 年，全園僅 320 株成樹。
4. **精確數字**：全手工採收糖度（Brix）$\ge 23^\circ$ 之全紅紫櫻桃果；2025 產季年產量僅 184 公斤（約 780 罐）。
5. **製程時間**：山泉水浮豆去皮後，進行 36 小時低溫有氧發酵（水溫穩定控制於 14.5°C），再置於高架棚架慢速日曬乾燥 21 天。
6. **烘焙細節**：德國 Probat 12kg 滾筒烘焙機，入豆溫 180°C，一爆密集後 1 分 15 秒出鍋，烘焙度 Agtron 72/85（淺焙）。
7. **風味實測**：乾香為白色茉莉花與佛手柑；注水後散發蜜桃汁、野薑花與荔枝果酸，餘韻帶烏龍茶清香。
8. **負向承諾**：絕不收購外圍未認證生豆、絕不做二次人工加香混配、出貨超過烘焙後 30 天之庫存豆一律自用不售。
9. **包裝實體材質**：可完全自然分解之日本和紙透氣閥袋，外層封以特富野鄒族傳統編織麻繩與手工木質號碼牌。
10. **代表人物**：高山小農負責人汪武雄（Mo'o Peongu），連續三屆阿里山生豆評鑑特等獎得主。

---

#### 階段二：頁面區塊論證結構 (Section Argument Writing)

| 區塊 (Section) | 爭點主張 (Claim) | 硬核客觀證據 (Proof) | 視覺與排版承載 (Layout & Typography) |
| :--- | :--- | :--- | :--- |
| **Section 1: 標題序曲 (Hero)** | 「這不是大工廠拼配的香氣，這是特富野海拔 1,280 公尺午後濃霧孕育的 184 公斤。」 | 標註當季總產量 184kg、批次編號 #2026-TF01、Brix 23° 糖度檢驗數據。 | 超大無襯線字級（120px+），深墨綠底色搭配淺米白文字，左側大字主張，右側特富野晨霧縮時靜態微距圖。無 CTA 按鈕，僅單純震撼的主張。 |
| **Section 2: 時間與溫度 (Process Proof)** | 「36 小時 14.5°C 冰泉低溫慢速發酵，只為保留花香而不是酒氣。」 | 呈現真實發酵槽溫度監控折線圖（14.5°C 恆溫）、糖度隨時間降解對比表、洗豆山泉水水質檢測報告（TDS 42ppm）。 | 橫向寬幅雙欄排版：左欄為冷酷精準的科學發酵數據矩陣，右欄為木質水洗槽浮豆真實檔案黑白照片。 |
| **Section 3: 烘焙檔案 (Roast Curve)** | 「在一爆密集後 75 秒精準出鍋，將果酸封存於茉莉花香的臨界點。」 | 公開 Roaster Scope 烘焙溫度曲線圖，標示 RoR（溫升率）、返煙點（102°C）與出鍋 Agtron 數值（72/85）。 | 滿版大圖背景疊加真實向量溫度曲線，配合大號數字統計（Agtron 72 / 75s / 180°C），無任何裝飾性幾何圖標。 |
| **Section 4: 負向邊界 (The Refusals)** | 「我們寧可下架，也不做以下三件事。」 | 明列三大不妥協：1. 絕不摻雜低海拔商用豆；2. 烘焙超過 30 天無條件報廢；3. 產量售罄即標記售罄，絕不追加預售。 | 純黑背景、朱紅警示粗字，三行簡明斷句排版，字級 32px，形成強烈視覺沉澱與品牌信任感。 |
| **Section 5: 認領與封裝 (Purchase / Claim)** | 「本產季尚餘 42 罐，每罐均由汪武雄手工親簽號碼牌。」 | 即時庫存倒數數字（非營銷倒計時，真實扣減）、實體麻繩木牌包裝 1:1 俯瞰圖。 | 單欄置中克制排版，單一購買按鈕，邊緣清楚展示包裝成分檢驗合格證。 |

## 3. 效益對比

| 指標 | 傳統 AI 生成網頁 (Slop) | 經本範本引導之網頁 (Subject-driven) |
| :--- | :--- | :--- |
| **標題文案** | 「體驗頂級咖啡的醇厚風味，每一口都是享受」 | 「特富野海拔 1,280 公尺，午後濃霧孕育的 184 公斤」 |
| **內容特色** | 三張卡片：高品質、快速配送、客戶滿意 | 四大硬核證據：發酵溫控數據、RoR 烘焙曲線、糖度檢測、負向清單 |
| **色彩與質調** | 通用 Tailwind 藍紫色、圓角大陰影、漸層背景 | 阿里山深林墨綠、黑砂土壤色、米白紙質、大字級高對比純色 |
| **訪客信任度** | 像模板套皮，難以信服 | 具備極強真實性、不可替代性與說服力 |
